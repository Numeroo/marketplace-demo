# Marketplace Demo

A responsive local marketplace built with Next.js App Router, React, TypeScript, Tailwind CSS, and Supabase. Users can publish listings with a photo, browse and search listings, view listing details, and message sellers.

## Quick start

1. Install Node.js 20+ and npm.
2. Follow [SETUP.md](./SETUP.md) to configure Supabase and environment variables.
3. Install and start the app:

   ```bash
   npm install
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000).

- Next.js 16 App Router and React 19
- TypeScript and Tailwind CSS 4
- Shadcn UI components
- Supabase Database and Storage
- Optional Resend email notifications
